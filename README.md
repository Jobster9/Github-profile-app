# Github-profile-app

React based project that pulls through Github API & displays some of a users public data & repositories.

## About

This project was built to demonstrate usage of react with tailwind, api intergration & hopefully good design structure.

## Tech stack

React 19.1.1
React-icons 5.5.0
Tailwind 4.1.14
Vite (build tool)
GitHub REST API (unauthenticated)

## Running the application

commands:
npm run build

npm run dev

npm run preview
